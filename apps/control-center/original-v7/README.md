# Control Center

Role: Super Admin

This application is the Segaloka platform Control Center.

It must not provide a production mechanism for switching into Travel,
Vendor, Traveler, Affiliate, Mitra, or Agen identities.

Existing V7 Control Center UI/UX remains the source of truth.

Portal code currently embedded in the legacy combined runtime will be
removed only after each role dashboard has been safely extracted and
validated.
